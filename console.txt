================================================================================
booting GEOS in console mode (fish shell)
================================================================================

GEOS picks the boot mode at runtime from the kernel cmdline token
`geos.mode=`. PID 1 reads /proc/cmdline before it spawns Xorg; if the
token says `console`, Xorg never starts and Emacs runs directly on
/dev/console with TERM=linux. No X, no EXWM, just Emacs filling the
framebuffer.

Default is `ui`. To boot console mode you change the cmdline.


--------------------------------------------------------------------------------
option A. one-shot boot via GRUB edit
--------------------------------------------------------------------------------

Cleanest path. Costs nothing. The choice does not survive a reboot.

  1. Build and start the dev VM:

       cd /path/to/emacs-os
       ./iso-build/dev-vm.sh

     (or, for the production ISO:)

       ./iso-build/emacs-os.sh

  2. The QEMU window opens on the GRUB menu. Highlight the GEOS entry
     and press `e` (lowercase). GRUB drops you into a line editor.

  3. Find the line that starts with:

       linux /gnu/store/...-linux-libre-... root=...

     Move to the END of that line (Ctrl-e in GRUB's editor) and append
     a single space, then:

       geos.mode=console

  4. Press Ctrl-x (or F10) to boot.

  5. On the serial console you should see:

       pid1: geos.mode=console, skipping Xorg, emacs on /dev/console

     The kernel framebuffer fills with Emacs. M-x eshell for the
     shell. M-x geos-poweroff to shut down.


--------------------------------------------------------------------------------
option B. permanent: bake the token into the image
--------------------------------------------------------------------------------

Edit the operating-system record so every boot lands in console mode.

  1. Open the system definition:

       nano guix-system/system.scm

  2. Find the kernel-arguments form (search for "kernel-arguments").
     It currently reads:

       (kernel-arguments
        (cons* "console=tty1"
               "console=ttyS0,115200"
               %default-kernel-arguments))

     Add "geos.mode=console" to the cons* list:

       (kernel-arguments
        (cons* "console=tty1"
               "console=ttyS0,115200"
               "geos.mode=console"
               %default-kernel-arguments))

  3. Rebuild and boot. From the repo root:

       ./iso-build/cleanup.sh
       ./iso-build/dev-vm.sh

     Cleanup is optional but discards the previous overlay so you
     definitely see the new cmdline.

  4. The GRUB entry now bakes geos.mode=console. Every cold boot lands
     in console mode without GRUB editing.


--------------------------------------------------------------------------------
option C. one-shot via QEMU -append (advanced)
--------------------------------------------------------------------------------

Only works with direct kernel boot (qemu -kernel ... -initrd ...). The
default path through the qcow2 boots through GRUB, which ignores
QEMU's -append. If you really want this, extract the kernel and
initrd from /gnu/store and pass them with -kernel/-initrd plus
-append "... geos.mode=console". Most of the time option A is
simpler.


--------------------------------------------------------------------------------
verifying you are in console mode
--------------------------------------------------------------------------------

Once Emacs is up, in the *scratch* (or any) buffer:

  M-: (with-temp-buffer (insert-file-contents "/proc/cmdline") (buffer-string))

The string ends in `geos.mode=console`. Also, `(display-graphic-p)`
returns nil in console mode and t in UI mode.


--------------------------------------------------------------------------------
fish-specific notes
--------------------------------------------------------------------------------

Nothing in the build path is fish-specific; the scripts are POSIX sh
under iso-build/. Fish runs them as external programs, so the calls
above (./iso-build/dev-vm.sh, etc.) work verbatim from a fish prompt.

If you ever pipe build output into fish (rare), remember fish does
NOT do `$()` command substitution; use `(...)` instead. Example:

  set -l qcow (./iso-build/dev-vm.sh --build-only)
  echo $qcow

That captures the qcow2 path without booting.
