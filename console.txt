================================================================================
booting GEOS in console mode (fish shell)
================================================================================

GEOS boots in UI (EXWM) mode by default. The image bakes
`geos.mode=ui` into kernel-arguments, and PID 1 also defaults to ui
if the token is missing or malformed. To land in console mode you
flip the cmdline token, either at the GRUB editor for one boot or in
system.scm for permanent.


--------------------------------------------------------------------------------
option A. one-shot console boot via GRUB edit
--------------------------------------------------------------------------------

For one boot only, swap the baked token from ui to console.

  1. Build and start the dev VM:

       cd /path/to/emacs-os
       ./iso-build/dev-vm.sh

     (or, for the production ISO:)

       ./iso-build/emacs-os.sh

  2. The QEMU window opens on the GRUB menu. Press `e` (lowercase)
     to enter the line editor.

  3. Find the line that starts with:

       linux /gnu/store/...-linux-libre-... root=...

     Locate the `geos.mode=ui` token on that line and change it to
     `geos.mode=console`.

  4. Press Ctrl-x (or F10) to boot.

  5. The serial console shows:

       pid1: geos.mode=console, skipping Xorg, emacs on /dev/console

     The kernel framebuffer fills with Emacs. M-x eshell for the
     shell. M-x geos-poweroff to shut down. Reboot reverts to UI.


--------------------------------------------------------------------------------
option B. permanent: flip the default in system.scm
--------------------------------------------------------------------------------

If you want console as the permanent default, edit the operating-
system record.

  1. Open the system definition:

       nano guix-system/system.scm

  2. Find the kernel-arguments form (search for "kernel-arguments").
     Change the geos.mode=ui string to "geos.mode=console":

       (kernel-arguments
        (cons* "console=tty1"
               "console=ttyS0,115200"
               "geos.mode=console"
               %default-kernel-arguments))

  3. Rebuild and boot. From the repo root:

       ./iso-build/cleanup.sh
       ./iso-build/dev-vm.sh

     Cleanup discards the old overlay so you definitely see the new
     cmdline.


--------------------------------------------------------------------------------
verifying which mode you are in
--------------------------------------------------------------------------------

Once Emacs is up, in the *scratch* (or any) buffer:

  M-: (with-temp-buffer (insert-file-contents "/proc/cmdline") (buffer-string))

Look for the geos.mode= token. Also, `(display-graphic-p)` returns
nil in console mode and t in UI mode, which is the cheapest sanity
check.


--------------------------------------------------------------------------------
fish-specific notes
--------------------------------------------------------------------------------

Nothing in the build path is fish-specific; the scripts are POSIX sh
under iso-build/. Fish runs them as external programs, so the calls
above (./iso-build/dev-vm.sh, etc.) work verbatim from a fish prompt.

If you ever pipe build output into fish (rare), remember fish does
NOT do `$()` command substitution; use `(...)` instead. Example:

  set -l qcow (./iso-build/dev-vm.sh --build-only)
  echo $qcow

That captures the qcow2 path without booting.
