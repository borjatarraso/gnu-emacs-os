================================================================================
booting GEOS in console mode (fish shell)
================================================================================

GEOS v0.3 boots in console mode by default. The image bakes
`geos.mode=console` into kernel-arguments, and PID 1 also defaults to
console if the token is missing or malformed. Both layers agree, so
you can boot the qcow2 or the ISO straight from the wrapper scripts
and you land in framebuffer Emacs.

If you want the GUI session instead, change the cmdline at GRUB or
edit system.scm and rebuild. Both paths are documented below.


--------------------------------------------------------------------------------
option A. just boot, you are already in console mode
--------------------------------------------------------------------------------

The default image bakes geos.mode=console. Build, boot, done.

  1. Build and start the dev VM:

       cd /path/to/emacs-os
       ./iso-build/dev-vm.sh

     (or, for the production ISO:)

       ./iso-build/emacs-os.sh

  2. The QEMU window opens on the GRUB menu. Let it auto-boot, or
     press Enter to boot the highlighted entry.

  3. On the serial console you should see:

       pid1: geos.mode=console, skipping Xorg, emacs on /dev/console

     The kernel framebuffer fills with Emacs. M-x eshell for the
     shell. M-x geos-poweroff to shut down.


--------------------------------------------------------------------------------
option B. one-shot UI boot via GRUB edit
--------------------------------------------------------------------------------

For one boot only, swap the baked token from console to ui.

  1. Boot as in option A, but at the GRUB menu press `e` (lowercase)
     to enter the line editor.

  2. Find the line that starts with:

       linux /gnu/store/...-linux-libre-... root=...

     Locate the `geos.mode=console` token on that line and change
     it to `geos.mode=ui`. (Or just append `geos.mode=ui` at the
     end; the LAST occurrence wins because pid1 takes the first
     match on a left-to-right scan and you should put the override
     in front, not behind. Easier to just edit the existing token.)

  3. Press Ctrl-x (or F10) to boot.

  4. The serial console now shows:

       pid1: geos.mode=ui, will spawn Xorg + EXWM

     Xorg comes up, EXWM grabs the root window, you get the GUI
     session. Reboot reverts to console.


--------------------------------------------------------------------------------
option C. permanent: flip the default in system.scm
--------------------------------------------------------------------------------

If you want UI as the new permanent default, edit the operating-
system record.

  1. Open the system definition:

       nano guix-system/system.scm

  2. Find the kernel-arguments form (search for "kernel-arguments").
     Change the geos.mode=console string to "geos.mode=ui":

       (kernel-arguments
        (cons* "console=tty1"
               "console=ttyS0,115200"
               "geos.mode=ui"
               %default-kernel-arguments))

  3. Rebuild and boot. From the repo root:

       ./iso-build/cleanup.sh
       ./iso-build/dev-vm.sh

     Cleanup discards the old overlay so you definitely see the new
     cmdline.


--------------------------------------------------------------------------------
verifying which mode you are in
--------------------------------------------------------------------------------

Once Emacs is up, in the *scratch* (or any) buffer:

  M-: (with-temp-buffer (insert-file-contents "/proc/cmdline") (buffer-string))

Look for the geos.mode= token. Also, `(display-graphic-p)` returns
nil in console mode and t in UI mode, which is the cheapest sanity
check.


--------------------------------------------------------------------------------
fish-specific notes
--------------------------------------------------------------------------------

Nothing in the build path is fish-specific; the scripts are POSIX sh
under iso-build/. Fish runs them as external programs, so the calls
above (./iso-build/dev-vm.sh, etc.) work verbatim from a fish prompt.

If you ever pipe build output into fish (rare), remember fish does
NOT do `$()` command substitution; use `(...)` instead. Example:

  set -l qcow (./iso-build/dev-vm.sh --build-only)
  echo $qcow

That captures the qcow2 path without booting.
