# images

<!-- voice: first person singular, lowercase, no em-dashes. -->

The project logos live here.  A PNG cannot carry a license notice
inside the file, so the copyright and license for these images are
stated here, in the same directory as the files, and again in the
inventory at `docs/MEDIA.md`.

Files in this directory:

  - `logo.png`      primary project logo, "editor on silicon".
  - `logo-256.png`  256x256 variant of `logo.png` for the README header.
  - `logo-128.png`  128x128 variant for embedded contexts and favicons.

All three are original work by me, drawn from scratch in GIMP; the
256 and 128 pixel variants are scaled-down derivatives of `logo.png`.
They contain no third-party trademarks, fonts, or stock-image
elements.
